# MediaSocial

Быстрый редактор постов для соцсетей с плагинной архитектурой.
Создан для музеев, библиотек и локальных сообществ.

## Что умеет
- Плагины для типовых постов: «Доброе утро», «Новость», «Погода», «Календарь»
- Простой фоторедактор: обрезка, поворот, яркость, контраст
- Текст и инфографика поверх изображения
- Загрузка данных из интернета (восход, погода, календарь)

## Как написать свой плагин
Реализовать IPlugin.
